# Privacy Policy

## Overview
This Chrome extension is designed with user privacy as a priority.  
It does **not** collect, store, transmit, or share any personal or sensitive user data.

## Data Collection
The extension does **not** collect any of the following:
- Personally identifiable information (such as name, email, or account details)
- Authentication information
- Financial or payment information
- Health information
- Personal communications
- Location data
- Web browsing history
- Website content
- User activity data (such as keystrokes, mouse movements, or clicks)

## Data Usage
All functionality of the extension is performed **locally within the user’s browser**.  
Any permissions requested (such as `tabs`, `storage`, or host permissions) are used **solely to provide the core functionality of the extension** and are not used to collect or transmit user data.

## Data Sharing
The extension does **not** share data with third parties.  
No data is transmitted to external servers or services.

## Data Storage
The extension does not persist personal or sensitive user data.  
If browser storage is used, it is limited to non-personal configuration or preference data required for the extension to function correctly.

## Changes to This Policy
If the extension’s functionality changes in a way that affects user data handling, this privacy policy will be updated accordingly.
