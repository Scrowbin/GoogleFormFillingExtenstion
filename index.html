Privacy Policy

Overview

This Chrome extension operates entirely within the user’s browser. We respect user privacy and are committed to transparency.

Data Collection

This extension does not collect, store, transmit, or share any personal or sensitive user data.

Specifically, the extension does not collect:

  • Personally identifiable information (such as name or email)
  • Health, financial, or authentication information
  • Personal communications
  • Location data
  • Web browsing history
  • Website content
  • User activity beyond what is required for the extension’s functionality

Data Usage

All processing occurs locally within the user’s browser. No data is sent to external servers or third parties.

Data Sharing

This extension does not share user data with any third parties.

Permissions

Any permissions requested by the extension are used solely to enable its user-facing features and are not used to collect or transmit user data.

Changes to This Policy

If the extension’s behavior changes in a way that affects user data handling, this privacy policy will be updated accordingly.
